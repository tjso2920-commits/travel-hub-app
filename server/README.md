# 서버 (사전 배포 상태)

로드맵 ⑧(유료 출시 준비) 실제 구현. **아직 아무 데도 배포되지 않았고,
공개 배포/실제 결제 승인은 이 서버가 하지 않는다.** 이 문서는 실제로
켜기 전에 사람이 결정·설정해야 하는 것을 한 번에 정리한다.

## 왜 서버가 필요한가

이 앱은 지금 서버 없는 정적 HTML + localStorage 구조다. 다음 4가지는
클라이언트 자바스크립트만으로는 원리적으로 안전하게 할 수 없다:

1. **장소 조회**: Google Places 같은 유료 API 키를 클라이언트에 넣으면
   그 키가 그대로 노출된다. 서버가 키를 들고 있어야 한다.
2. **무료체험 1회 제한**: 클라이언트 값은 사용자가 항상 조작할 수 있다
   (브라우저 저장소 지우기 등). "성공 1회"를 서버가 세야 한다.
3. **결제 확인**: "결제했다"는 클라이언트의 자기 신고는 조작 가능하다.
   결제대행사(PG)의 웹훅을 서버가 직접 받아야 한다.
4. **계정별 데이터**: 여러 기기에서 같은 코스를 보려면 계정과 서버
   저장소가 있어야 한다.

## 지금 상태 — 실제로 구현·테스트된 것

- Node 내장 `http` + `node:sqlite`(Node 22, 별도 설치 불필요)만 사용.
  프레임워크·외부 패키지 없음 — `node server/index.mjs`로 바로 뜬다.
- 이메일 + 매직 코드 로그인(비밀번호 없음). 기존 회원 재로그인은
  재가입 없이 처리.
- 계정별 코스 저장/조회 — `account_id`는 세션 토큰에서만 뽑는다
  (요청 본문 값을 신뢰하지 않는다 — 계정 격리의 핵심).
- 무료체험 1회 소진 — DB의 PRIMARY KEY 제약으로 "동시 요청·재시도
  에도 딱 1번만 성공"을 보장한다(서버 테스트에서 20개 동시 요청 →
  정확히 1개 성공을 실제로 재현·확인함).
- 결제 웹훅 서명 검증(HMAC, 타이밍 공격 방지) + 이벤트 ID 기반 멱등성
  (같은 이벤트 재전송해도 중복 반영 안 됨).
- 가격은 코드에 숫자로 안 박고 서버 설정값(`config.mjs`)에서만 읽는다.
  **9,900원/30일은 확정 가격이 아니라 ChatGPT가 검토 중인 가설이다**
  (`docs/BUSINESS_DECISIONS.md` 참고).
- 장소 조회·결제·이메일 전부 **어댑터 패턴**이다 — 실제 크리덴셜이
  하나라도 없으면 서버 전체가 자동으로 테스트 모드로 돈다(절반만
  실제 모드로 도는 상태를 방지). 테스트 모드에서도 실제 코드 경로
  (요청 검증 → DB 반영 → 응답)는 전부 동일하게 탄다 — 어댑터만 가짜다.

## 테스트

```
node server/test/server.test.mjs
# 또는
npm run server-test
```

`:memory:` SQLite로 매번 깨끗하게 시작한다. 32개 검사 — 계정 격리,
동시 요청 상황의 무료체험 소진, 위조/정상 웹훅 서명 처리, 로그인
코드 재사용 거부 등을 전부 실제 HTTP 요청으로 확인한다.

## 실제 운영 전환에 필요한 것 (전부 한 번에)

**절대 채팅창에 실제 비밀키·크리덴셜을 붙여넣지 마세요.** 아래는
어떤 값이 어디에 필요한지 정리한 목록이다 — 실제 값은 서버가 실행될
환경(예: 호스팅 서비스의 환경변수 설정 화면)에 직접 입력해야 한다.

| 필요한 것 | 환경변수 | 없으면 무슨 일이 생기나 |
|---|---|---|
| 서버를 실제로 어딘가에 올리기(호스팅) | — | 지금은 로컬에서만 실행됨. Node를 지원하는 아무 호스팅(예: 작은 VM, 컨테이너 서비스)이면 됨 |
| 장소 조회 API 키(Google Places 등) | `GOOGLE_PLACES_API_KEY` | 없으면 테스트 어댑터(가짜 좌표)가 계속 쓰임 |
| 결제대행사(PG) 가맹점 시크릿 | `PAYMENT_PG_SECRET` | 없으면 실제 결제 승인 불가 — 테스트 모드 유지 |
| 결제 웹훅 서명 검증용 비밀값(PG가 발급) | `PAYMENT_WEBHOOK_SECRET` | 기본값은 테스트 전용 문자열 — 운영에 쓰면 안 됨 |
| 실제 이메일 발송 계정/키 | `EMAIL_API_KEY` | 없으면 로그인 코드가 실제로 전송 안 됨(테스트 어댑터가 기록만 함) |
| 확정 가격 | `PRICE_AMOUNT_KRW`, `PRICE_PERIOD_DAYS` | 지정 안 하면 가설값(9,900원/30일) 그대로 사용됨 — ChatGPT 확정 필요 |
| 자동결제 여부 결정 | `PRICE_AUTO_RENEW` | 기본값 false(자동결제 아님) — 켜려면 명시적 사용자 동의 UI가 먼저 있어야 함 |

이 중 하나라도 없으면(`GOOGLE_PLACES_API_KEY`·`PAYMENT_PG_SECRET`
둘 다 있어야 실제 모드로 전환됨) 서버는 항상 테스트 모드로 강제
전환된다 — "절반만 실제"인 상태로 조용히 운영되는 사고를 막기 위해서다.
