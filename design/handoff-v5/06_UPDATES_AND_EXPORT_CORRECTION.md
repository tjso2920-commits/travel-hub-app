# 최신 정정 및 장소 추가 요구사항

## Takeout 선택 정정
이 문서가 기존 Saved-only 안내보다 우선한다. 사용자 캡처의 '지도(내 장소)' 설명은 별표 표시된 장소와 리뷰다. 일반 저장 목록은 Saved, 별표도 썼거나 구분이 불명확하면 Saved + 지도(내 장소)를 함께 내보낸다. 위쪽 일반 지도(환경설정 및 개인 장소)는 이번 기본 가져오기에 필수로 안내하지 않는다. 모든 파일이 CSV라고 가정하지 말고 내 장소의 JSON 등 실제 형식을 확인한다. 리뷰/설정 데이터는 장소 목록과 구분하고 불필요한 데이터는 수입하지 않는다.
근거: https://support.google.com/maps/answer/7280933?co=GENIE.Platform%3DDesktop&hl=ko 및 사용자 Takeout 캡처.

## 초기 수입과 이후 업데이트는 별개
Takeout 파일은 내보낸 시점의 사본이다. 구글맵 저장 변경이 현재 앱에 실시간 자동 반영되는 기능은 구현되지 않았다. 공식 개인 목록 API/권한을 확인하기 전 자동동기화를 약속하지 않는다.

제품 요구사항:
1. 처음: ZIP/CSV/지원 JSON 등 여러 장소를 한번에 가져오기.
2. 여행 중: 구글맵 개별 장소 공유 링크 복사 → 앱의 장소 추가에 붙여넣기 → 검증된 장소 식별 → 저장. 현재 디자인에는 실제 링크 가져오기 구현 없음. 단축 URL, 중복, 식별 실패를 검증. iOS 공유 메뉴에서 직접 앱으로 받기는 설치형태/브라우저 지원 별도 검증 전 약속 금지.
3. 많은 장소가 추가된 후: 최신 내보내기 파일 재수입 → 새 장소 추가, 기존 동일 장소 중복 방지, 사용자의 메모/분류/방문기록/일정 보존. 이름만으로 합치지 않기. 같은 장소의 여러 목록 소속 보존. 애매한 변경은 사용자 확인.
4. 파일에 없다는 이유로 기존 장소를 자동 삭제하지 않는다. 부분 내보내기 가능성이 있으므로 삭제 동기화는 별도 확인 대상으로 둔다.
5. 성공/기존/변경/미확인 개수를 실제 파서 결과로 보여준다. 두 번째 동일 파일 수입은 새 중복을 만들지 않아야 한다.
6. 구글맵에서 저장만 해도 앱으로 자동 동기화되는 것과, 공유 링크를 통해 앱에 추가하는 것을 분명히 구분한다.

권장 제품 설명: 처음에는 한 번에 가져오고, 이후에는 장소 링크로 바로 추가하세요. 실제 기능 검증 후에만 사용.
