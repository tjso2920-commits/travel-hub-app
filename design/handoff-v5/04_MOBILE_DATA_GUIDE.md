# 아이폰에서 실제 저장 목록 준비

이미 여행웹에 넣었던 실제 CSV가 있다면 그 파일부터 사용하세요. 새로 내보낼 필요는 없습니다. 없다면 Safari에서 Google Takeout으로 내보내세요. 구글맵 앱의 목록 공유 링크와 내보낸 데이터 파일은 다릅니다.

1. https://takeout.google.com/ 접속 → 구글맵 저장에 사용하는 계정으로 로그인.
2. 전체 선택을 해제하고 **저장됨(Saved)** 항목을 선택하고 별표 장소도 포함하려면 **지도(내 장소)**를 함께 선택. 구글 공식 지도 도움말이 안내하는 저장 목록 내보내기 항목입니다. 계정/언어에 따라 표시가 다를 수 있습니다.
3. 다음 단계 → 이메일로 다운로드 링크 받기 → 한 번 내보내기 → ZIP → 내보내기 생성.
4. 준비 완료 메일에서 다운로드 → 아이폰 파일 앱에 저장. 다운로드 폴더는 Safari 설정에 따라 iCloud Drive 또는 나의 iPhone에 있을 수 있습니다.
5. ZIP 그대로 Claude/ChatGPT에 첨부해도 됩니다. 앱에 파일 첨부 기능이 보이지 않으면 PC로 옮겨 Claude Code의 프로젝트 외부 작업 폴더에 두고 경로를 알려주세요.
6. CSV만 찾고 싶다면 파일 앱에서 ZIP을 탭해 압축을 풀 수 있습니다. 내보낸 파일이 CSV인지 JSON인지, 장소명/좌표가 들어 있는지는 실제 파일을 확인해야 합니다. 직접 변환하거나 열 이름을 고치지 마세요.

일반 저장 목록은 Saved, 별표 장소는 지도(내 장소)를 함께 선택합니다. 위쪽 일반 지도 항목은 이번 기본 가져오기에는 선택하지 않아도 됩니다. Gmail·사진 등 전체 계정 데이터를 함께 내보낼 필요가 없습니다. 구글은 내보내기 준비에 몇 분에서 며칠이 걸릴 수 있다고 안내합니다. 다운로드가 즉시 안 된다고 앱 오류로 단정하지 마세요.

현재 새 디자인의 '샘플 파일로 체험하기'는 실제 ZIP/CSV 업로드 기능이 아닙니다. 준비한 원본은 먼저 개발 검증 자료로 전달합니다. 내보낸 목록 수가 기대와 다르면 다른 계정/다른 종류의 저장 항목인지 확인하고, 누락 원인은 실제 자료를 보고 조사합니다.
