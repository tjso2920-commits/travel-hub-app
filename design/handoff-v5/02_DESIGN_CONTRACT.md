# 승인 디자인 보존 계약

## 기준과 역할
- 사용자 승인 기준은 approved-design/ 실제 코드다. Plotline 캡처를 새로 해석해서 다시 만들지 않는다.
- ChatGPT: 사업/UX 방향과 디자인 코드. Claude: 기능·데이터·API·통합·오류 수정·검증.
- 디자인 원본은 별도 폴더로 그대로 보존하고 실행 앱에 필요한 부분을 이식한다. 적절한 컴포넌트 분리는 허용하나 결과의 외형은 유지한다.
- 같은 코드라도 CSS 충돌·폰트 로딩·브라우저에 따라 달라질 수 있다. 동일 화면을 실제 비교하기 전 '100% 동일'이라고 보장하지 않는다.

## 유지할 시각 요소
- 크림 배경 #f7f6f2, 본문 #335563, 파랑 #4388a5, 청록 #52aaa8.
- 영문 Nunito Sans, 한글 Noto Sans KR. 현재 폰트 파일 및 라이선스 동봉. Plotline 원본과 동일 폰트라는 뜻은 아님.
- 둥근 검색창, 프로필 아바타, 여행지 선택·내 주변 분리.
- 기울어진 흰 사진첩, 사진 중심 카드, 카드의 선택 버튼.
- 모바일 2열 카드, 넓은 화면 3열; 현재 600px breakpoint와 max-width 1040px를 기본 유지.
- 하단 내 스팟 / 사진첩 / 오늘 동선 / 프로필, 선택 시 나타나는 동선 담기 바.
- 모달/시트의 둥근 모서리·배경·버튼·위계. 글꼴 굵기·간격은 spots.css 후반 typography refinement 포함 전체 규칙이 기준.

## 변경 허용
장소명·도시·사진·메모·개수·지역별 분류는 실제 데이터로 바뀐다. 데모 표시와 미연결 안내는 해당 기능을 구현하고 검증한 뒤에만 제거한다. 입력 sanitization, 접근성 보완, 이벤트 바인딩, 상태 관리, 오류 처리, 긴 글씨 대응은 기능 통합에 필요한 변경이다. 브랜드명 변경이나 새 탭·새 화면 디자인은 이번 통합 범위가 아니다.

## 코드별 역할
| 파일 | 처리 |
|---|---|
| index.html | 승인 DOM/레이아웃. 기존 앱 전역 CSS에 오염되지 않도록 스타일 범위 격리 |
| spots.css | 전역 디자인/모바일/시트/폰트. 단순 색상만 복사하지 말고 전체 기준 유지 |
| spots.js | 샘플 데이터와 UI 이벤트. 실데이터 어댑터로 대체; 파서/지도 API는 없음 |
| assets/*.webp | 샘플용 분위기 사진. 실제 매장 식별용 사진 아님 |
| assets/fonts/* | 로컬 폰트와 SIL OFL 라이선스. 외부 CSS @import를 재도입하지 않기 |
| classic.html / landing.html / shots / icon* / manifest / sw.js | 이전 미리보기 호환용. 새 기능 소스나 승인된 신규 디자인 기준으로 삼지 말 것 |

## 폰트 중요 제한
현재 한국어 폰트는 디자인에 쓰인 문자만 포함한다. 실제 CSV의 새 문자는 시스템 폰트로 대체될 수 있다. 최종 출시에는 같은 Noto Sans KR의 전체 문자 범위를 unicode-range 분할 등으로 제공하고, 외국어 장소명도 누락 없이 렌더링해야 한다. 폰트를 다른 제품으로 바꿔 해결하지 않는다.
