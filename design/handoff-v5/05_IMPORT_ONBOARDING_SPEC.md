# 사용자 추가 확정: Takeout 안내도 제품의 일부

'Google Takeout에서 CSV를 준비하세요' 한 줄로 끝내지 않는다. 사용자에게 새 용어를 외우게 하지 말고, 버튼과 단계별 설명으로 **어디를 열고 무엇을 선택하고 무엇을 다운로드할지** 알려준다. 아래는 승인 디자인을 유지하면서 구현할 안내 문구/상태 계약이다. 최신 사용자 요구로 앞 문서의 가져오기 요구사항을 보완한다. 현재 미리보기에는 기존 간단 안내만 있으며 아래 상세 안내 전체가 구현된 상태는 아니다.

## 진입
제목: 구글맵에 저장한 곳, 가져오기
설명: 구글에서 내 목록 파일을 한 번 받아오면 도시별로 정리해 드려요.
주 버튼: 처음이에요 · 파일 받는 방법
보조 버튼: 이미 파일이 있어요
샘플 버튼: 내 파일 없이 먼저 체험하기
회원가입/위치 권한/숙소/여행 날짜 선행 요구 없음. 안내를 건너뛰고 이미 받은 파일을 선택할 수 있어야 함.

## 단계별 실제 문구
화면은 한 단계씩 보여주되 '전체 단계 보기'로 펼칠 수 있게 한다. 외부 페이지 동작은 자동 확인한 척하지 않는다.

1/5 · 구글 페이지 열기
본문: 아래 버튼으로 구글의 데이터 다운로드 페이지를 열어주세요. 구글맵에서 장소를 저장한 계정으로 로그인하세요.
버튼: 구글에서 내 목록 받기 ↗
링크: https://takeout.google.com/
보조: 새 탭에서 진행한 뒤 이 앱으로 돌아오세요.

2/5 · 필요한 항목만 선택하기
본문: 먼저 '모두 선택 해제'를 누른 뒤, 목록에서 '저장됨(Saved)'을 선택하세요. 별표로 저장한 장소도 가져오려면 '지도(내 장소)'도 함께 선택하세요.
보조: Gmail이나 Google 포토를 고를 필요는 없어요. 화면 아래 '다음 단계'를 누르세요.
도움말: '저장됨'이 안 보여요 → 브라우저의 '페이지에서 찾기'로 '저장' 또는 'Saved'를 검색해 보세요. 그래도 없다면 계정과 화면의 항목을 확인해야 합니다. 엉뚱한 항목을 무조건 대신 선택하라고 안내하지 마세요.
주의: 'Google 지도'라는 이름만 보고 해당 항목만 선택하면 사용자 맞춤 저장 목록과 다른 데이터를 받을 수 있으므로, 구글 공식 저장 목록 안내의 Saved 항목을 기준으로 한다. 화면 명칭은 계정/언어에 따라 달라질 수 있다.

3/5 · ZIP으로 내보내기
본문: 전송 방법은 '이메일을 통해 다운로드 링크 전송', 빈도는 '한 번 내보내기', 파일 형식은 '.zip'으로 선택하세요. 파일 크기 항목은 기본값을 그대로 둬도 됩니다. 마지막으로 '내보내기 생성'을 누르세요.
보조: ZIP은 여러 파일을 담은 묶음이에요. 엑셀로 열거나 CSV로 바꿀 필요가 없어요.

4/5 · 완료 메일에서 다운로드
본문: 구글이 준비 완료 메일을 보내면 메일의 다운로드 버튼을 눌러 ZIP 파일을 저장하세요. 요청 접수 메일과 파일 준비 완료 메일은 다를 수 있어요.
보조: 몇 분에서 며칠 걸릴 수 있어요. 기다리는 동안 샘플로 먼저 둘러볼 수 있어요.
버튼: 기다리는 동안 샘플 보기
주의: 고정 몇 초 타이머/가짜 진행률/자동 완료 표시 금지. 구글 작업 상태를 읽을 수 없으면 사용자가 알려준 상태만 표시.

5/5 · 이 앱으로 돌아오기
본문: 아래 '받은 파일 선택'을 누르고 방금 저장한 ZIP을 골라주세요. 아이폰은 '파일' 앱의 다운로드 폴더에서 찾을 수 있어요.
버튼: 받은 ZIP 또는 CSV 선택
도움말: 다운로드 폴더는 Safari 설정에 따라 iCloud Drive 또는 나의 iPhone에 있을 수 있어요.
주의: **실제 ZIP 파서 연결과 검증 완료 뒤에만 이 버튼을 실제 업로드로 활성화.** 현재 디자인 데모는 기능 연결 전임을 표시. 업로드가 끝나기 전 성공 결과를 보여주지 않는다.

## 돌아왔을 때 끊기지 않기
안내 단계는 필요하면 기기 안에 복원 가능한 상태로 유지한다. 외부 페이지 열기 전 입력한 위치/계정 정보가 필요하지 않도록 한다. 앱 복귀 시 시작 화면으로 리셋하지 않고 '파일을 받으셨나요?'와 파일 선택을 보여준다. 실패해도 원본 파일을 지우거나 전체 과정을 반복시키지 않는다.

## 오류/미지원 상태 문구
- 아직 파일을 못 받음: 구글 준비 완료 메일을 기다려주세요. 샘플은 지금 둘러볼 수 있어요.
- 다른 파일: 저장 목록을 찾지 못했어요. 구글에서 받은 저장됨(Saved) ZIP 또는 목록 CSV인지 확인해 주세요.
- 일부 파일 지원 안 됨: 이 형식은 아직 읽지 못해요. 지원 형식을 구체적으로 안내하고 내용 수작업 편집을 강요하지 않음.
- 일부 장소 누락: X곳을 정리했어요. Y곳은 위치 확인이 필요해요. → 정리된 장소 먼저 보기 / 확인할 장소 보기.
- 내보낸 목록 수와 예상 수가 다름: 실제 파일에 있는 개수를 우선 표시하고 기대 숫자를 맞추기 위해 샘플을 보충하지 않는다.

## 계측/검증
사용자 1명이라도 안내 없이 처음 가져오기를 수행하게 관찰: 어느 단계에서 멈춤, 완료 시간, 같은 버튼 반복, 파일 찾기 실패. 실제 iPhone Safari에서 다운로드·앱 복귀·파일 선택까지 검증해야 '모바일 가져오기 완료'라고 보고 가능.

## 한계
Takeout은 구글 외부 페이지다. 구글 자체 단계를 앱에서 없앴다고 주장할 수 없다. 앱에서 없앨 수 있는 수고는 CSV 직접 찾기·압축 해제·열 이름 수정·형식 변환이다. 실제 ZIP 읽기 기능을 구현해야 이 약속이 성립한다. 구글 로그인만으로 목록이 자동 동기화된다고 홍보하지 않는다.
