## 1. 이 앱은 무엇인가

구글맵에 저장만 해 둔 장소를 실제로 갈 수 있는 동선으로 바꾸고, 현지 언어 학습·통역까지
한 화면에서 다루는 여행 앱. **단일 HTML 파일**, 외부 라이브러리·CDN·빌드 도구 없음,
데이터는 전부 브라우저 `localStorage`에만 있고 서버로 나가지 않는다.

- 사용 환경: 아이폰 + iOS Safari 기준. 홈 화면에 아이콘으로 추가해 PWA처럼 씀.
- 유지보수자는 개발자가 아니다. 결론부터 짧게, 그다음 최소 설명.

## 2. 원본 파일 위치 — 반드시 여기서 시작

```
private/personal.html   ← 진짜 원본. 모든 수정은 여기서 시작한다.
```

`src/index.html`은 **생성물**이다. `scripts/build-sales.mjs`가 `private/personal.html`을
읽어 6곳을 문자열 치환해서 만든다 (판매자 개인 신상 제거용). **`src/index.html`을 직접
고치면 다음 빌드 때 사라진다.**

### ⚠️ `private/personal.html`이 원본인지 확인한 방법 (요청하신 검증)

`private/`는 `.gitignore`에 걸려 있어 깃허브에 올라간 적이 없다. 2026-09-07에 작업 컨테이너가
초기화되면서 이 파일이 실제로 사라진 적이 있다. 그때 복구한 방법:

1. 깃허브에 남아 있는 `src/index.html`(판매용, 생성물)을 가져옴
2. `scripts/build-sales.mjs`에 적힌 6개 치환 규칙을 **역으로** 적용해서 `private/personal.html`을 재구성
3. 재구성한 파일로 `npm run build`를 다시 돌려 나온 `src/index.html`이 깃허브의 것과
   **바이트 단위로 완전히 일치**하는지 확인 → 일치함을 확인함

이 ZIP에 든 `private/personal.html`은 이 복구 이후 계속 이어서 작업한 버전이고,
**지금 이 순간에도 같은 방법으로 재검증 완료**(아래 "지금 상태" 참고). 즉 지금 원본은
신뢰할 수 있는 원본이다. 단, 이 사실 자체는 다음에 새 에이전트가 작업을 이어받을 때도
컨테이너가 다시 초기화될 수 있다는 뜻이므로 **작업 시작 전 항상 커밋·푸시부터 하고
시작할 것**을 권한다. (아래 6절의 복구 절차를 그대로 재사용할 수 있게 남겨 둔다.)

### `build-sales.mjs`의 치환 규칙 (복구용 참고표 — `rep()` 호출 6회)

| # | 개인용 → 판매용 |
|---|---|
| 1 | `const SALE_MODE=false;` → `true;` |
| 2~4 | 일본어 회화 예문 3개 (요식업 경력이 드러나는 문장) → 경력 무관 문장으로 각각 교체 |
| 5 | 주차 소제목 `'경력 소개'` → `'관심 소개'` |
| 6 | 대화 화자 이름 `'윤식'` → `'학습자'` |

각 치환은 `scripts/build-sales.mjs`의 `rep()` 호출로, 반드시 1회만 일치해야 하고
아니면 빌드가 즉시 실패한다(조용한 누락 방지). 정확한 문자열은 그 파일을 직접 볼 것.

## 3. 실행 방법

빌드 도구가 없으므로 "실행"은 사실상 파일을 여는 것이다.

```bash
# 개인용(원본)을 브라우저로 직접 열어서 확인
open private/personal.html          # 또는 그냥 더블클릭

# 검사 도구를 쓰려면 의존성 설치(jsdom·playwright — 둘 다 devDependency)
npm install

# 판매용 생성 (원본 수정 → 이 명령 → src/index.html 갱신)
npm run build

# 기능 검사 47종 × 두 빌드(개인용/판매용)
npm test

# 무결성 검사 (보호 블록·저장 키·개인정보 흔적)
npm run verify

# 화면 검수 — 실제 Chromium으로 대비·터치영역(44px)·가로넘침·콘솔 오류 확인
npm run audit

# 위 세 개를 한 번에 (커밋 전 필수)
npm run check

# 로컬에서 브라우저로 미리보기 서버 (선택)
npm run preview
```

`npm run audit`는 Chromium 실행 파일 경로가 필요하다. 기본값은
`/opt/pw-browsers/chromium-1194/chrome-linux/chrome` (이전 작업 환경 전용 경로)이고,
다른 환경에서는 `CHROMIUM_PATH` 환경변수로 재지정한다:

```bash
CHROMIUM_PATH=/path/to/chrome npm run audit
```

Playwright 브라우저가 따로 없으면 `npx playwright install chromium`으로 받는다.

## 6. `docs/HANDOFF.md` 이후 작업 요약 (44절 → 지금)

기능 감사(QA) 9라운드를 거치며 나온 굵직한 수정들. 시간순:

1. **다국어 확장** — 통화(`FM_MONEY`)·음식 분류(`FM_KINDS_NOW`)·구역(`FM_REGIONS_NOW`)이
   나라별로 갈아 끼워지게 함. 이전엔 일본 전용 상수가 하드코딩돼 있었음.
2. **환율이 나라를 안 따라가던 버그** — 나라를 바꿔도 이전 환율을 그대로 써서
   1,000바트가 "약 9,300원"(실제 4만원대)으로 나오던 것. `fxPairOK()`로 통화 짝이
   안 맞으면 아무것도 안 보여주게 고침.
3. **구역 필터가 후쿠오카에서만 동작하던 버그(가장 컸음)** — 도쿄·오사카·파리 등에서
   장소가 0개로 보이던 문제. `fmInArea()`에서 "잴 근거 없으면 빼지 않는다" 원칙으로 수정.
4. **구글맵 URL에서 좌표 직접 추출** (`fmCoordFromUrl`) — Places API 없이도 CSV의
   URL만으로 위/경도를 뽑아냄. 사업적으로 API 유료 등록 여부를 좌우하는 핵심 수정.
5. **분류 자동판정이 일본 밖에서 안 먹히던 버그** — 터키 0/6, 베트남 1/6 등. 순서
   기반 규칙(`FM_INFER`)으로 재작성.
6. **타임아웃 0개였던 버그** — 신호가 끊기면 통역·환율·날씨 기능이 영구히 잠기던 것.
   `fetchWait()` + `NET_WAIT=25000`으로 25초 후 사람이 읽을 수 있는 오류로 전환.
7. **두 번째 여행을 못 가던 버그** — 나라를 바꿔도 이전 여행 장소·숙소·날짜가 안
   지워지던 것. `fmSetCountry()`에서 확인창 후 백업·초기화(`tripReset`).
8. **저장 실패 무통보 문제** — 사파리 시크릿 모드에서 저장이 막혀도 몰랐던 것.
   `saveFailed()` + `#saveBar` 알림.
9. **CSV 고르는 법 안내 강화 + 정품 코드 UX** — 구매자가 어느 csv 파일을 골라야
   하는지 몰라 137곳 중 20곳도 못 넣던 문제, 30곳 제한에 걸렸을 때 정품 코드 입력칸을
   못 찾던 문제. 화면 안내·자동 스크롤·상단 띠 추가.
10. **터치 영역 44px, 화면 검수 자동화** — `scripts/audit.mjs`로 실제 Chromium
    렌더링에서 대비·터치영역·iOS 확대유발(입력칸 16px 미만)·가로넘침을 6가지
    화면 크기로 검사.
11. **오늘(2026-09-09 직전) 작업 — 시각 테마 전면 교체 (PAPER)** — 아래 7절 참고.

이 기간 동안 기능 검사가 21종 → **47종**(`t1.mjs` ~ `t47.mjs`)으로 늘었다.
`README.md`에는 아직 "28종"이라고 적혀 있었는데 이번에 47로 고쳤다(README도 갱신함).

## 7. 지금 디자인 상태 — 이어받을 사람이 꼭 알아야 하는 것

### 테마 아키텍처

`private/personal.html`의 `<style>` 안에는:

1. **최초 `:root{}` 블록** (파일 맨 앞부분) — 어두운 배색의 원조 팔레트. **건드리지 않는다**
   (README 절대 규칙). 지금은 사실상 죽은 코드다 — 아래 2번이 항상 덮어쓴다.
2. **`body{...}` 로 시작하는 시각 레이어 블록** — 이게 실제로 화면에 적용되는 테마다.
   지금은 `/* PAPER · 종이 테마 */` 주석으로 시작한다(파일에서 검색하면 바로 찾음).
   기존 방식 그대로 "테마를 통째로 다시 칠하고 싶으면 이 블록 전체를 새로 쓴다"이다.
   과거 테마 이름들(GRAPHITE WARM → DAYLIGHT → PAPER)은 git 이력에서 diff로 볼 수 있다.

- **가로 스크롤 생기면 안 됨.**
- 검사는 6가지 화면 크기(320~390px 폭 × 100~140% 글자 크기)로 돈다.

## 10. 절대 규칙 (README와 동일, 다시 강조)

1. 판매용(`src/index.html`)을 직접 고치지 않는다 — 개인용 고치고 `npm run build`
2. `private/`를 커밋하지 않는다 (`.gitignore`가 이미 막고 있음, 그대로 유지)
3. API 키를 코드에 넣지 않는다 — 사용자가 앱 화면에서 직접 입력, `localStorage`에만 저장
4. 커밋 전 `npm run check` 전부 통과
5. 화면을 고쳤으면 `npm run audit`도 통과 확인
6. 배포 시 `src/sw.js`의 `CACHE` 버전을 올린다
7. 최초 `:root` 블록, 기존 `localStorage` 키 이름(`ai`, `as_chat_v1`, `foodmap_v1`,
   `jp_chat_v1`, `jp_packs_v1`, `jp_state_v1`), 탭 전환 로직은 건드리지 않는다
