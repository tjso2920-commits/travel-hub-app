# 스레드·인스타 홍보 전략 — 별표털기

목표: 후쿠오카 항공권 200만원 = **9,900원 × 약 200개** (수수료 떼면 약 230개)
기간: 지금 ~ 2026-10-25 출발까지 약 3개월
가진 것: 팔로워 0, 시간 없음, 사진 없음, **대신 진짜 이야기가 있음**

---

## 0. 먼저 냉정하게

형님은 **여행 인플루언서가 될 수 없습니다.** 시간도 없고 여행 사진도 없습니다.
그 판에서 싸우면 집니다.

대신 형님한테만 있는 게 셋 있습니다. 이걸로 싸웁니다.

1. **문제가 너무 구체적이다** — "구글맵에 별표만 쳐놓고 안 감"
   이건 거의 모든 사람이 겪는데 아무도 말로 꺼낸 적이 없습니다
2. **주방에서 일하는 사람이 만들었다** — 개발자가 만든 앱보다 스레드에서 훨씬 셉니다
3. **내가 쓰려고 만들었다** — 10월에 진짜로 후쿠오카에 갑니다. 이게 서사입니다

**스레드에 90%, 인스타에 10%.**

## 3. 3주 계획 — 순서가 전부다

### ⛔ 절대 하면 안 되는 것
- **첫 글부터 "앱 만들었습니다 사주세요"** → 그 계정은 거기서 끝납니다
- 매일 홍보 글 → 사람들이 나갑니다

### 1주차 — 문제만 던진다 (판매 얘기 0)

목적: "어 나도 그런데" 를 모읍니다. 팔 생각을 아예 하지 마세요.

**글 1 (제일 센 거. 이걸 먼저)**
```
구글맵 열어봤는데 별표 137개.

그중에 실제로 간 곳 11개.

나머지 126개는 뭐냐
```

**글 2**
```
여행 가서 밥 때 되면
구글맵 별표 목록 스크롤 계속 내리다가
결국 눈앞에 보이는 데 들어간 적 있으면 손

나만 그런 거 아니지
```

**글 3**
```
저장할 때는 "여기 꼭 가야지" 였는데
막상 가면 어디가 어딘지 모르겠고
숙소에서 먼지 가까운지도 모르겠고

결국 안 감
```

→ 1주차는 이 3개면 충분합니다. **댓글에 다 답해주세요.** 그게 다음 글 재료입니다.

### 2주차 — 만드는 과정을 깝니다 (build in public)

목적: "이 사람 진짜 만드네" 를 보여줍니다. 레벨스가 하는 방식입니다.

**글 4**
```
주방에서 14시간 일하고
집 와서 앱 만든다

10월에 후쿠오카 가는데
별표 137개를 어떻게 돌아야 할지 몰라서
```

**글 5 (화면 캡처 1장 첨부)**
```
구글맵에서 별표 목록 뽑아서 넣었더니
숙소에서 가까운 순서로 오늘 코스를 짜줌

내가 쓰려고 만든 건데
생각보다 잘 되네
```

**글 6 (실패도 깝니다 — 이게 신뢰를 만듭니다)**
```
파리로 바꿔서 켰더니
목록이 통째로 비어 있음

일본 좌표만 보게 짜놨더라
하루 날렸다
```

### 3주차 — 출시

**글 7 (출시글)**
```
만들었다.

구글맵 별표 목록 넣으면
숙소·시간·거리 보고 오늘 갈 순서를 짜줌
가게 앞에서 쓸 현지 회화도 나옴

9,900원. 선착순 50명.
(내 후쿠오카 항공권값 모으는 중)
```

**글 8 (첫 판매 — 숫자를 다 깝니다. 스레드에서 제일 잘 먹힙니다)**
```
오늘 처음 팔았다. 9,900원.
수수료 떼고 8,712원.

항공권까지 199개 남음.
```

→ 이 "숫자 까기" 를 계속 하세요. **이게 형님 콘텐츠입니다.**
   1개 → 10개 → 50개. 사람들이 응원하러 옵니다.

## 4. 계속 쓸 수 있는 글감 (마르지 않음)

형님은 **여행 사진이 없어도** 이걸로 계속 씁니다.

1. **숫자 공개** — 오늘 몇 개 팔림, 총 얼마, 목표까지 얼마
2. **버그 이야기** — "산 사람이 파리 넣었는데 비어 있다고 함. 고쳤다"
3. **주방 이야기** — 일하면서 만드는 것 자체가 콘텐츠
4. **후쿠오카 준비** — 10월까지 카운트다운. D-83, D-50…
5. **손님 후기** — 산 사람 말 그대로 (허락받고)
6. **일본어 공부** — 90일 교재 쓰는 사람이 실제로 공부하는 모습

## 7. 현실적인 숫자

정직하게 말씀드립니다.

- 신규 계정으로 3개월에 200개는 **쉽지 않습니다**
- 하지만 **스레드 글 하나가 터지면 하루에 50개도 됩니다**
- 그래서 글을 계속 써야 합니다. 하나가 터질 때까지

**터질 확률이 제일 높은 글은 1주차 글 1번** ("별표 137개, 간 곳 11개") 입니다.
숫자가 구체적이고, 누구나 자기 폰을 열어보게 만들기 때문입니다.

**크몽도 같이 봐야 합니다.** 크몽은 검색으로 알아서 팔립니다.
스레드는 초기 부스터고, 크몽이 바닥을 깔아줍니다.
