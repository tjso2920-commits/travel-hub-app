# 판매 채널 3개 — 역할 분담

스레드 · 카톡 오픈채팅 · 크몽. 셋 다 한다.
**중요한 건 셋이 다른 일을 한다는 것이다.** 안 나누면 오픈채팅방이 고객센터가 되고,
주방에서 일하는 동안 문의가 쌓여서 감당이 안 된다.

| 채널 | 하는 일 | 안 하는 일 |
|---|---|---|
| **스레드** | 사람 **모으기** | 파는 것 |
| **오픈채팅** | 모인 사람 **붙잡기** · 소식 알리기 | 1:1 문의 받기 |
| **크몽** | **돈 받기** · 환불 · CS | 사람 모으기 |

    스레드에서 보고 → 오픈채팅 들어와서 지켜보다가 → 크몽에서 산다

---

## 1. 카톡 오픈채팅 — 만드는 법

카카오톡 → **채팅** 탭 → 우측 상단 **말풍선(+)** → **오픈채팅** → **그룹 채팅방**

### 설정값 (이대로 하면 된다)

| 항목 | 값 | 이유 |
|---|---|---|
| 방 이름 | **별표털기 · 구글맵 별표 터는 사람들** | 검색으로 들어온다 |
| 검색 허용 | **켜기** ⭐ | **안 켜면 링크로만 들어온다. 이게 유입 경로다** |
| 참여 코드 | **걸지 말 것** | 진입장벽 |
| 해시태그 | `여행` `후쿠오카` `구글맵` `여행계획` | 검색에 걸린다 |
| 내 프로필 | 익명 가능 | 실명 안 써도 된다 |

### 방 소개글 (그대로 복사)

```
구글맵에 별표만 쳐놓고 안 간 곳들, 이번엔 실제로 가 봅시다.

· 별표털기 앱 소식 / 새 버전 안내
· 여행 계획 짜다 막힌 것 물어보기
· 다녀온 곳 공유

만든 사람은 주방에서 일합니다.
답은 보통 밤에 답니다. 급한 건 크몽 문의로 주세요.
```

### 🔴 지옥 방지 — 이 한 줄이 제일 중요하다

**공지에 반드시 박을 것:**

```
[공지]
· 구매·환불·결제 문의 → 크몽으로 (거기가 빠릅니다)
· 여기는 소식 / 사용법 / 잡담
· 답변은 밤에 몰아서 합니다 (주방 일합니다)
```

이거 안 박으면 1:1 문의가 전부 여기로 온다.
크몽은 문의 응대를 시스템으로 처리해 주는데, 그걸 굳이 형님이 손으로 받을 이유가 없다.

### 오픈채팅의 진짜 값어치

사람들이 착각하는 게, 오픈채팅은 **파는 곳이 아니다.** 이걸로 버는 게 아니다.

진짜 값어치는 셋이다.
1. **새 버전 알리기** — 앱 고쳤을 때 여기다 한 줄 쓰면 끝
2. **산 사람이 안 떠나게** — 여행 갔다 와도 방에 남아 있으면 다음에 또 산다
3. **자연 홍보** — 방에서 "이거 좋더라" 한마디가 스레드 글 열 개보다 세다

## 2. 크몽 — 돈 받는 곳

개인이 직접 돈을 받으려면 통신판매업 신고·환불 처리·세금계산서를 다 해야 한다.
**크몽이 그걸 전부 대신한다.** 수수료 약 20%는 그거 안 하는 값이다.

9,900원 팔면서 그 귀찮음을 떠안을 이유가 없다.

### 등록할 때 넣을 값

- 가격 **9,900원**
- 설명 맨 위 `출시 기념 · 선착순 50분 (이후 19,900원)`
- 50개 팔리면 **직접 들어가서 19,900으로 고친다.** 자동 아니다

### 팔린 뒤 흐름

    크몽에서 결제 → 크몽 메시지로 앱 주소 + 정품 코드 전달 → 오픈채팅 초대

정품 코드는 구매자 이름으로 하나씩 만들어야 한다. Claude 한테
"이 이름으로 코드 만들어줘" 하면 1초다.

⚠️ **절대 쓰면 안 되는 말**: "원어민 감수", "전문가 검수"
회화 문장은 일본어 포함 전부 AI 가 만든 것이고 감수를 안 받았다.

## 3. 스레드 — 사람 모으는 곳

자세한 건 `docs/홍보전략.md`.

핵심만: **첫 글에 앱 얘기를 하지 마라.** 문제만 던진다.

```
구글맵 열어봤는데 별표 137개.

그중에 실제로 간 곳 11개.

나머지 126개는 뭐냐
```

프로필 링크에는 **오픈채팅 주소**를 건다. (크몽 아니다 —
아직 안 산 사람한테 결제 페이지를 들이밀면 도망간다)

## 4. 소개 페이지 버튼 배치

`src/landing.html` 의 `신청하기` 버튼 3곳이 지금 `#apply` 라 죽어 있다.
채널이 정해졌으니 이렇게 나눈다.

| 버튼 | 연결 |
|---|---|
| 맨 위 · 맨 아래 **구매** 버튼 | **크몽 상품 링크** |
| 중간 **소식 받기 / 물어보기** | **오픈채팅 링크** |

**두 주소가 나오면 Claude 한테 주면 넣어 준다.**

---

## 5. 만드는 순서

1. **오픈채팅방 먼저** (5분) — 스레드 프로필에 걸 링크가 필요하다
2. **스레드 계정 + 첫 글** — 앱 얘기 없이 문제만
3. **크몽 등록** — 사람이 좀 모인 뒤에 해도 늦지 않다
4. 두 링크를 Claude 한테 → 소개 페이지 완성

**오픈채팅방과 스레드는 크몽보다 먼저 열어도 된다.**
파는 물건이 없어도 "만드는 중" 이야기로 사람이 모인다. 그게 레벨스 방식이다.
