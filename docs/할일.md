한 단계 끝나면 알려주시고, 이상한 게 있으면 그 화면만 캡처해서 보내주시면 됩니다.

## 🔴 1단계 — 오늘 이거부터 (30분)

### 1. 137곳 CSV 를 앱에 다시 넣어 보기

**왜 이게 1번인가**: 좌표가 있느냐 없느냐로 이 앱이 되느냐 마느냐가 갈린다.
좌표가 없으면 지도·거리·오늘 동선·구역 자동 묶기가 전부 죽는다.

전에는 137곳 전부 좌표 0개였다. 그런데 CSV 를 뜯어 보니
**위도·경도 칸은 없어도 URL 칸 안에 좌표가 들어 있는 경우가 많았다.**
앱이 그걸 안 꺼내 쓰고 있었다 — 이제 꺼내 쓴다.

**할 일**
1. 아이폰에서 앱 열기
2. `담기` 탭 → **`CSV·백업 불러오기`**
3. `fukuoka-137.csv` 고르기
4. 목록에서 아무 곳이나 눌러 보기

**보고 알려주실 것 (이 한 줄이면 됨)**
> "137곳 중 지도 뜨는 게 ○곳"

- **100곳 넘게 뜬다** → 끝. Places API 안 사도 된다. 2단계로 간다
- **거의 안 뜬다** → 아래 2번(Takeout)을 한다

### 2. (1번이 실패했을 때만) Google Takeout

1. `takeout.google.com` 접속
2. **"모두 선택 해제"** 누르기
3. **지도(내 장소)** 만 체크
4. 맨 아래 **내보내기** → 메일로 링크 옴 (몇 분~몇 시간)
5. ZIP 풀기 → 안에 있는 `.json` 또는 `.geojson` 파일을 찾기
6. 그 파일을 앱 `담기` → `CSV·백업 불러오기` 로 넣기
7. 장소 눌렀을 때 지도가 뜨면 성공

## 🟡 2단계 — 내 폰에 설치하고 직접 써 보기 (1시간)

파는 사람이 안 써 본 물건을 남한테 팔 수는 없다.

### 3. 개인용을 내 폰에 올리기

⚠️ **개인용에는 137곳 메모(지인 이름 등)가 들어 있다.**
그래서 개인용은 **GitHub 에 안 올린다.** Netlify 로 나만 아는 주소를 만든다.

1. `travel-app-deploy.zip` 압축 풀기
2. `app.netlify.com/drop` 접속
3. 압축 푼 **폴더를 통째로** 화면에 끌어다 놓기
4. 나온 주소를 **아이폰 사파리**로 열기
5. 아래 **공유 버튼** → **홈 화면에 추가**
6. 그 주소는 **아무한테도 알려주지 않는다**

### 4. Gemini 키 넣기 (무료 · 카드 등록 없음)

이걸 안 넣으면 AI 기능(통역·사진 읽기·회화팩 만들기·하루 코스)이 전부 안 돈다.

1. 앱 오른쪽 위 **`⚙`** 누르기
2. **`🔑 키 발급 페이지 열기`** 누르기
3. 구글 로그인 → **`Create API key`** → 나온 글자 **복사**
4. 앱으로 돌아와 두 번째 칸에 **붙여넣기** → **`저장`**
5. **`연결 테스트`** 눌러서 🟢 나오는지 확인

### 5. 직접 써 보기 — 이 순서대로

한 번에 다 하지 마시고, 하나씩 하고 이상하면 바로 말씀해 주시라.

1. **목록** — `담기` 탭에서 `분류별로` 눌러 보기. 식당·바·카페가 제대로 나뉘어 있나
2. **지도** — 아무 가게나 눌러서 지도가 뜨나
3. **오늘 동선** — `일정` 탭 → 숙소 정하고 → 코스가 짜지나
4. **통역** — `지금 여행` 탭 맨 위
   - 🎤 눌러서 한국어로 말하기 → 일본어로 번역되고 **소리로 읽어주나**
   - 📷 눌러서 아무 글씨나 찍기 → 뭐라고 써 있는지 나오나
   - 손글씨 메뉴판도 한 번 찍어 보기
5. **회화** — `일본어` 탭 → 오늘 6문장이 나오나, 🔊 눌러서 소리가 나나
6. **나라 바꾸기** — `담기` → `세팅 다시 하기` → 목적지를 **파리**로 바꿔 보기
   - 돈 단위가 유로로 바뀌나
   - 탭 이름이 `프랑스어`로 바뀌나
   - 회화팩 만들기가 되나 (1~2분 걸림)

**이상한 게 있으면 그 화면 캡처해서 보내주시면 됩니다.**

## 🟢 실기기에서만 확인 가능한 것

이 작업 환경은 외부 접속이 막혀 있어서 내가 실제 응답을 한 번도 못 봤다.
안 되면 앱은 멀쩡히 돌고 그 기능만 안 뜬다. 결과만 알려주면 내가 고친다.

### 6. 날씨 뜨는지
`지금 여행` 탭 → 날씨 카드 → 가져오기 → 숫자가 들어오는지

### 7. 환율 뜨는지
`일정` 탭 → 환율 패널 → 값이 들어오는지

### 8. 아이폰 단축어로 공유 담기
`담기` 탭 안내대로 단축어 만들고, 인스타/구글맵에서 공유 → 앱에 들어오는지

### 8-2. 통역 실제로 써보기 — **팔기 전에 반드시**
`지금 여행` 탭 맨 위. 실기기에서만 확인된다.
- **🎤 한국어로 말하기** → 일본어로 소리가 나오는지 (스피커 볼륨 확인)
- **🎤 일본어 듣기** → 한국어로 뜨는지
- **📷 사진으로 읽기** → 메뉴판 말고도 **간판·안내문·표·약봉투·기계 버튼**으로 찍어 보기.
  글자만 옮기는 게 아니라 **맨 위에 "이게 뭐다" 한 줄**이 뜨는지가 핵심
- ⭐ **손글씨·붓글씨 세로 메뉴판**으로 꼭 시험해 보시라. 인쇄 메뉴는 아무나 읽는다.
  나무판에 붓으로 쓴 이자카야 메뉴가 진짜 시험대다. 안 읽히면 `🔍 더 꼼꼼히 다시 읽기` 도 눌러 보고 결과 알려주기
- 더 꼼꼼히 다시 읽기는 **좋은 모델(gemini-2.5-pro)** 을 쓴다. 무료 한도가 빨리 차므로 자주 쓰면 막힐 수 있다
- **⌨ 말해서 쓰기** → `🎤 말해서 쓰기` 누르고 한국어로 말하면 **글자가 칸에 쌓이는지**.
  말하는 중간에도 보이는지, 여러 문장을 이어 말해도 끊기지 않는지(아이폰이 잘 끊는다),
  틀리게 알아들었을 때 **손으로 고치면 고친 대로 번역되는지**
- **📢 크게 보여주기** 가 화면 가득 뜨는지
- 마이크 권한: 아이폰 설정 → 사파리 → 마이크 **허용**

파파고보다 나은 점이 여기서 갈린다. 안 되면 알려주면 고친다.

## 💰 가격·판매 (문서: `docs/가격_판매전략.md`)

### 14. 크몽에 등록할 때 넣을 값 (소개 페이지에는 이미 반영해 뒀다)
- 가격 **9,900원**, 설명 맨 위에 `출시 기념 · 선착순 50분 (이후 19,900원)`
- 50개 팔리면 형님이 들어가서 **가격을 19,900으로 고친다.** 자동은 없다
- 크몽 최소 판매가 기준이 있을 수 있으니 등록할 때 확인

### 15. 크몽 판매자 등록
계정 만들고 상품 등록까지는 내가 못 한다. 상품 설명·썸네일 문구는 내가 써 둔다.

### 16. 저작권 등록 — **지금은 안 해도 됨. 팔리기 시작하면** (문서: `docs/복제방지_법적보호.md`)
`www.cros.or.kr` (한국저작권위원회) → 프로그램 저작물로 온라인 등록. 수수료 몇 만원.

**시점을 다시 정리**: 등록의 이점(법정손해배상)은 **침해가 생기기 전에** 등록돼
있으면 쓸 수 있다. '판매 전' 이 아니라 '침해 전' 이다.
아직 아무도 모르는 물건은 아무도 안 훔친다. **첫 판매가 나오고 사람들이 알기
시작할 때** 하면 충분하다. 저작권 자체는 지금도 이미 형님 것이다.

주의: 등록하면 저작자 본명이 공개 열람 대상이 된다. 그게 싫으면 미리 생각할 것.

### 6·7번째 검사 — 날짜, 그리고 손가락 크기

**날짜·시간은 깨끗했다.** 자정 넘는 술집(22-03시), 브레이크타임, 24시간 영업,
과거 날짜, 뒤집힌 날짜, 윤년·월말 넘김 — 전부 맞았다. 여기는 손댈 게 없었다.

**손가락 크기는 아니었다.** 기존 화면 검수가 390px 한 가지 크기에 40px 기준으로
button 만 보고 있어서 아래가 전부 통과하고 있었다.

    접는 제목            17~20px  ×4
    🔊 듣기 버튼          29px    ×12
    음성 고르는 칸         30px    ×2
    입력칸 · 작은 버튼     40px    ×30
    큰 버튼 · 고르는 칸    42px    ×15

애플이 정한 최소가 44px 이다. 42px 은 눈에 안 보이게 자꾸 헛눌린다.
전부 44px 로 올렸다.

**그리고 더 큰 것 하나 — 입력칸 글씨가 14px 이었다.**
아이폰 사파리는 입력칸 글씨가 16px 보다 작으면 **탭하는 순간 화면을 확대**한다.
글자를 넣을 때마다 화면이 튀고 손으로 다시 줄여야 했다. 16px 로 올려서 안 그런다.

**검사 기준 자체를 고쳤다.** 이제 `npm run audit` 이
- 44px 기준으로 본다(40px 이 아니라)
- button 뿐 아니라 **고르는 칸·링크·접는 제목·입력칸**까지 본다
- 입력칸 글씨가 16px 미만이면 잡는다
- **화면 크기 4가지**로 본다 — 아이폰 SE1(320) · SE2/3(375) · 글씨 140% · 작은 폰+큰 글씨

안 그러면 다음에 새로 만든 버튼이 또 그냥 통과한다.

### 8번째 검사 — 오프라인 · 저장 · 새 버전

여행 앱에서 제일 위험한 쪽을 처음으로 봤다.

네트워크를 끊고 다시 열어 봤다 — 앱이 뜨고, 담은 12곳도, 회화 6문장도,

다만 **오프라인이 통째로 죽을 수 있는 구멍**이 있었다.
캐시에 담을 때 `addAll` 을 썼는데, 이건 **하나라도 실패하면 전부 안 담긴다.**
파일 하나가 404 이거나 담는 도중 잠깐 끊기면 캐시가 통째로 비고,
그러면 오프라인이 죽는데 사용자에게는 아무 신호가 없다.
→ 하나씩 담게 고쳤다. 아이콘도 같이 담는다.

### 🔴 저장이 막혀도 아무도 몰랐다

    function save(k,v){try{...;return true;}catch(e){return false;}}

`false` 를 돌려주는데 **부르는 곳 어디에서도 확인하지 않았다.**
저장이 막혀도 화면은 멀쩡히 돈다. 그리고 앱을 닫으면 그날 담은 게 통째로 없어진다.

이렇게 되는 경우 — **아이폰 사파리 시크릿 모드**(제일 흔하다),
아이폰 저장 공간 부족, 사파리에서 사이트 데이터를 막아 둔 경우.

"담아 놨는데 다 사라졌다" 는 산 사람 입장에서 최악이다.
→ 저장이 막히면 화면 위에 빨간 줄로 알려 준다. 한 번만.

**크기 자체는 문제가 아니었다.** 137곳 + 90일 진도 + 회화팩 3나라 + 지출 200건을
다 넣어도 **155KB — 사파리 한계(5MB)의 3%** 다. 넘칠 일이 없다.
