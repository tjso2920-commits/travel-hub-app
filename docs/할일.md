## 🔴 지금 당장 — 이거 하나로 사업 모델이 갈린다

### 1. Google Takeout 에 좌표가 들어있는지 확인

**왜 중요한가**: 구글맵 목록을 CSV로 뽑으면 위경도가 안 나온다(137곳 전부 0개, 확인함).
좌표가 없으면 지도·동선·구역 묶기가 전부 죽는다. 이 앱의 핵심이다.
Takeout JSON 에 좌표가 들어있으면 **Places API 를 아예 안 사도 된다.**

**방법**
1. takeout.google.com 접속
2. **"모두 선택 해제"** 누르고 **지도(내 장소)** 만 체크
3. 내보내기 → 메일로 링크 옴 (몇 분~몇 시간)
4. ZIP 풀어서 안에 있는 `.json` 또는 `.geojson` 파일을 앱 `담기` 탭 → `CSV·백업 불러오기` 로 넣기
5. 장소를 눌렀을 때 **지도가 뜨면 성공**

**결과 알려주기**: 좌표 들어옴 / 안 들어옴

## 🟡 앱 실제로 써보기 (판매 전에 반드시)

### 2. 여행앱 개인용 설치
- `travel-app-deploy.zip` 압축 풀기
- app.netlify.com/drop 에 폴더 통째로 끌어다 놓기
- 나온 주소를 아이폰 사파리로 열고 → 공유 → **홈 화면에 추가**
- ⚠️ 이 주소엔 137곳 메모(지인 이름)가 올라간다. 남한테 알려주지 말 것

### 3. 137곳 넣기
- `fukuoka-137.csv` 를 아이폰 **파일에 저장**
- 앱 → `담기` 탭 → **`CSV·백업 불러오기`** → 그 파일 선택
- (1번이 성공하면 이건 Takeout 파일로 대체)

### 4. Gemini 키 넣기 — 무료, 카드 없음
- 앱 우측 상단 **`⚙`**
- **`🔑 키 발급 페이지 열기`** → 구글 로그인 → `Create API key` → 복사
- 2번 칸에 붙여넣기 → `저장` → **`연결 테스트`** → 🟢 확인

### 5. 운동앱 최신본으로 갈아끼우기
- `cutting-tracker.zip` 압축 풀기
- Netlify 기존 사이트에 덮어쓰기 (주소 유지 → 기록 유지)
- 아직 기록이 없으면 백업 안 받아도 됨

## 🟢 실기기에서만 확인 가능한 것

이 작업 환경은 외부 접속이 막혀 있어서 내가 실제 응답을 한 번도 못 봤다.
안 되면 앱은 멀쩡히 돌고 그 기능만 안 뜬다. 결과만 알려주면 내가 고친다.

### 6. 날씨 뜨는지
`지금 여행` 탭 → 날씨 카드 → 가져오기 → 숫자가 들어오는지

### 7. 환율 뜨는지
`일정` 탭 → 환율 패널 → 값이 들어오는지

### 8. 아이폰 단축어로 공유 담기
`담기` 탭 안내대로 단축어 만들고, 인스타/구글맵에서 공유 → 앱에 들어오는지

### 9. 사진 위치정보(HEIC)
`지금 여행` 탭 → 사진 올리기 → 찍은 장소·시각이 읽히는지
(안 되면 아이폰 설정 → 개인정보 보호 → 위치 → 카메라 확인)

## 🔵 GitHub 배포 켜기 (판매용)

지금까지 한 번도 배포된 적이 없다. 워크플로가 `main` 을 보는데 이 저장소 기본
브랜치는 `master` 였다. 그건 내가 고쳤고, 아래는 내가 못 만지는 설정이다.

### 10. Pages 설정
- GitHub → `travel-hub-app` → **Settings** → **Pages**
- Source 를 **`GitHub Actions`** 로 변경

### 11. 저장소를 Public 으로 바꾸기
**확인해 보니 `travel-hub-app` 이 지금 Private 이다.** 무료 플랜은 공개 저장소만
Pages 가 되므로 이대로면 판매용 주소가 안 생긴다.

- `private/` 폴더는 `.gitignore` 로 GitHub 에 아예 안 올라간다. 공개해도 137곳 메모·
  개인 신상은 나가지 않는다. 올라가 있는 것은 판매용 코드와 문서뿐이다
- Settings → 맨 아래 Danger Zone → **Change visibility → Public**

### 11-2. 운동앱은 Public 으로 바꾸지 말 것
`cutting-traker` 는 파일 안에 체중·나이·근무 시간표가 그대로 들어 있다.
공개하면 아무나 본다. **Netlify 로만 배포한다.**

### 12. 미리보기 링크로 전체 화면 훑고 피드백
배포 안 하고도 폰에서 바로 볼 수 있게 **미리보기 페이지**를 올려 뒀다(대화창에 링크).
판매용 빌드 그대로에 지어낸 예시 20곳만 넣은 것이라 개인 데이터는 안 들어간다.

미리보기에서 안 되는 것(배포하면 됨): 지도 타일·AI·날씨·환율 — 바깥 서버에 못 붙어서다.

화면 검수기로 대비·터치영역은 전부 통과시켰지만,
**실제 폰에서 보는 느낌은 다르다.** 어색한 곳 아무거나 알려주면 고친다.

특히 봐줄 것:
- 장소를 눌렀을 때 뜨는 **상세 시트** — 이게 구매 결정 화면이다
- `일정` 탭 → **`✨ AI가 하루 짜주기`**
- 지도에 **길·건물이 보이는지** (안 보이면 회색 배경만 나온다)
