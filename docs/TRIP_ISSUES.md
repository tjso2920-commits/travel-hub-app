# 후쿠오카 현장 사용 중 발견한 문제 (2026-10-25, 여행 중 기록)

**지금 고치는 것이 아니라 "다녀온 뒤 고칠 목록"이다.** 여행 중에는 코드를 바꾸지 않는다(노트북에서 돌고 있는 앱을 다시 배포·재시작해야 해서 위험).

## 이번에 확인된 것 (실제 화면 근거)
- 아이폰이 5G(모바일 데이터)로 노트북 앱에 접속되고, 노트북에서 가져온 장소가 폰에 동기화된다.
- 장소 상세에서 "방문 완료 표시"와 "마지막 방문 취소"가 동작하고 새로고침 후에도 확인했다(사용자 확인).
- 가져온 CSV·JSON 218곳이 도시별로 분류돼 보이고, 구글맵 링크는 맞게 열린다.

## 아직 확인 안 된 것
- 실제 구글 키를 쓴 위치 확인·영업시간·경로, 아이폰 GPS(`http`라서 안 됨), 일본 현지 네트워크에서의 장시간 사용.
