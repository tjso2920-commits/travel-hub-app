# 여행 통합 허브 앱

구글맵에 저장만 해 둔 장소를 **실제로 돌 수 있는 동선**으로 바꾸고, 그 가게에서 쓸 **현지 언어**까지 한 앱에서 다룬다.

외부 라이브러리·CDN 의존이 하나도 없는 단일 HTML 웹앱이다. 데이터는 전부 사용자 기기의 브라우저 저장소에만 있고 서버로 나가지 않는다.

---

## 저장소 구조

```
private/          ← .gitignore 로 제외됨. 절대 커밋하지 않는다
  personal.html     개인용 마스터. 모든 수정은 여기서 시작한다
  후쿠오카_137.csv   개인 장소 데이터(지인·가족 이름 포함)
src/              ← GitHub Pages 로 배포되는 폴더
  index.html        판매용. 생성물이므로 직접 수정하지 않는다
  sw.js             오프라인 캐시
  manifest.webmanifest, icon-*.png
scripts/
  build-sales.mjs        개인용 → 판매용 생성기
  verify.mjs             개인용·판매용 전체 검사(로컬)
  verify-sales-only.mjs  판매용만 검사(CI·배포 전)
  test/                  JSDOM 기능 검사 12종 + 실행기
docs/
  HANDOFF.md        전체 작업 이력. 새 작업자는 이것부터 읽는다
```

## 명령

```bash
npm install          # jsdom 설치 (검사용)
npm run build        # 개인용 → 판매용 생성
npm run verify       # 개인용·판매용 무결성 검사
npm test             # 기능 검사 (두 파일 전부)
npm run check        # build + verify + test 한 번에
```

## 절대 규칙

1. **판매용(`src/index.html`)을 직접 수정하지 않는다.** 개인용을 고치고 `npm run build` 를 돌린다. 직접 수정분은 다음 생성 때 사라진다.
2. **`private/` 를 커밋하지 않는다.** 개인 신상과 지인·가족 이름이 들어 있다.
3. **API 키를 코드에 넣지 않는다.** 키는 사용자가 앱 화면에서 입력하고 브라우저 저장소에만 있는다.
4. 커밋 전 `npm run check` 가 전부 통과해야 한다.
5. 앱을 새로 배포하면 `src/sw.js` 의 `CACHE` 버전을 올린다. 올리지 않으면 사용자가 옛 버전을 계속 본다.

## 배포

`main` 에 푸시하면 GitHub Actions 가 판매용을 검사하고 `src/` 만 GitHub Pages 로 올린다.
`private/` 는 저장소에 없으므로 배포 대상에 애초에 포함되지 않는다.

무료 플랜은 공개 저장소에서만 Pages 를 지원한다. 개인용 마스터와 사업 메모를 감추고 싶으면
별도의 **비공개 저장소**(Pages 없이 보관만)를 하나 더 두면 된다. 비공개 저장소 자체는 무료다.

어떤 결함을 어떻게 잡았는지, 무엇을 건드리면 안 되는지가 전부 적혀 있다.

**2026-07-30 부로 운동/운동2 탭과 관련 코드(`V`, `personalDays()`, 달력, 칼로리·단백질
계산, 체중 프로필)는 이 앱에서 완전히 삭제됐다.** (HANDOFF 35절 참고) 이 앱은 이제
여행(일본어 학습 + 후쿠오카 지도) 전용이다.

특히 다음은 건드리지 않는다.

- 최초 `:root` 블록
- 기존 localStorage 키 이름과 구조 (`ai`, `as_chat_v1`, `foodmap_v1`, `jp_chat_v1`, `jp_packs_v1`, `jp_state_v1`)
- 탭 전환, 여행 D-day(`TRIP_DATE`)

## 다른 나라·다른 언어로 넓힐 때

장소 쪽 로직은 나라와 무관하다. CSV 임포트, 분류, 필터, 거리, 구역 자동 묶기,
동선 최적화, 구글 지도 딥링크는 어느 도시에서도 그대로 동작한다.

나라마다 갈아 끼워야 하는 것은 셋뿐이다.

1. `FM_KINDS` — 음식·업종 분류 단어
2. Places 조회 기준 좌표와 검색어 접미사
3. `SJ_BANK` 문장 은행과 90일 학습 콘텐츠 — **태그 구조는 그대로 두고 문장만 교체한다**

구역 자동 묶기가 좌표 기반이라 도시별 지역 사전은 필요 없다.
